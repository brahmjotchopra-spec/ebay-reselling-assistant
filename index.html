eBay Reselling Assistant — Privacy Policy

Updated 7 November 2026

About the application

The repository owner uses this application to prepare draft listings in their own eBay seller account.

Information the application may access

The operator authorises the eBay Inventory API through OAuth. The tool reads inventory and offer records and can create an inventory item and an unpublished offer from an approved product file.

How information is used

The application uses seller information to check access, match existing inventory, prepare approved drafts and verify that an offer is still unpublished.

Storage, security and third parties

Product files and CSV exports are kept by the operator. When the operator runs the GitHub workflow, GitHub holds the configured credentials and private product file as Actions secrets and passes them to the runner. The program sends seller credentials only to eBay. Public workflow logs report credential presence, counts and outcomes. eBay retains inventory and offer records in the seller account. GitHub Pages hosts this public page.

Choices and deletion

The operator can revoke the grant in their eBay account, remove Actions secrets and workflow logs in GitHub, and delete local product files and exports. Each provider manages retention of records held in its own service.

Changes to this policy

This policy may be updated when development progresses and before any changes in how the application handles account information. The date at the top will be updated when the policy changes.

Contact

For general questions about the code, visit the project's public issues page. The repository owner administers the only seller account served by the application. Account access and deletion requests can be handled privately through the operator's authenticated eBay or GitHub support channel.
