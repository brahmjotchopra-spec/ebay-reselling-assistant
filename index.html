eBay Reselling Assistant — Privacy Policy

Last updated: 29 October 2026

About the application

eBay Reselling Assistant is a personal-use application under development, intended to help its operator prepare and manage listings in their own eBay seller account. This page explains the intended use of account information and the current development status.

Information the application may access

With the account holder's authorisation, the application is intended to request eBay permissions to manage inventory and offers, and to access selling-account settings and business policies. These may involve listing details, stock information, prices and other information needed to prepare listings. eBay authorisation uses OAuth; the application does not need the user's eBay password.

How information is used

Authorised eBay information is intended to be used only to prepare, review, create, update and manage listings at the account holder's direction, and to operate related seller settings. The application is not intended to sell personal information or use seller account information for advertising.

Storage, security and third parties

The application is still being developed. Its production data storage, access controls, retention periods and any service providers have not yet been finalised. Those arrangements must be documented here before the application processes or stores live seller account data. This public page is hosted through GitHub Pages; GitHub's own privacy practices apply to visits to the website.

Choices and deletion

Account holders can withdraw the application's eBay access through the relevant eBay account permissions. A private process for requesting access to or deletion of any data retained by the completed application must be provided and documented before live use.

Changes to this policy

This policy may be updated when development progresses and before any changes in how the application handles account information. The date at the top will be updated when the policy changes.

Contact

For general questions about the project, visit the project's GitHub issues page. GitHub issues are public: do not post your password, access tokens or personal information there. A private privacy-support contact channel must be provided before the application begins processing live user data.
